### Problem 82: Sum of Digits in a Given Number
**Difficulty:** Easy | **Tags:** Recursion, Math, Digital Root

**Problem Statement**
Given an integer `num`, repeatedly add all its digits until the result has only one digit, and return it.

**Input Format**
* A single line containing an integer `num`.

**Output Format**
* Print the single digit result.

**Constraints**
* $0 \le num \le 10^9$

**Examples**
**Input:** `529`
**Output:** `7` (Explanation: 5 + 2 + 9 = 16 -> 1 + 6 = 7)

**Input:** `101`
**Output:** `2`

**Input:** `8291`
**Output:** `2` (Explanation: 8 + 2 + 9 + 1 = 20 -> 2 + 0 = 2)
