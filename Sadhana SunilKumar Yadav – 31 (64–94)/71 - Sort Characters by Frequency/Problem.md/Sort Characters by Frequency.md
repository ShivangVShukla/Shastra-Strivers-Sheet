### Problem 71: Sort Characters by Frequency
**Difficulty:** Medium | **Tags:** Strings, Hash Table, Sorting

**Problem Statement**
You are given a string `s`. Return the array of **unique** characters, sorted by **highest to lowest** occurring characters.

If two or more characters have the same frequency, arrange them in **alphabetical order**.

**Input Format**
* A single line containing the string `s`.

**Output Format**
* Print the unique sorted characters separated by a space on a single line.

**Constraints**
* $1 \le s.length \le 10^5$
* `s` consists of English lowercase characters.

**Examples**
**Input:** `tree`
**Output:** `e r t`

**Input:** `raaaajj`
**Output:** `a j r`
