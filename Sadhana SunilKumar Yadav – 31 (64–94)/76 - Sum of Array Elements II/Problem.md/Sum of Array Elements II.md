### Problem 76: Sum of Array Elements II
**Difficulty:** Easy | **Tags:** Recursion, Arrays

**Problem Statement**
Given an array `nums`, find the sum of elements of the array using recursion.

**Input Format**
* The first line contains an integer `N`, the number of elements.
* The second line contains `N` space-separated integers.

**Output Format**
* Print the sum of array elements.

**Constraints**
* $1 \le N \le 10^3$
* $-10^4 \le nums[i] \le 10^4$

**Examples**
**Input:**
```
3
1 2 3
```
**Output:** `6`

**Input:**
```
3
5 8 1
```
**Output:** `14`
