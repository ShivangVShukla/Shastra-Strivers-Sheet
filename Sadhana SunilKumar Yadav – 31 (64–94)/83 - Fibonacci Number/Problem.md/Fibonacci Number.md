### Problem 83: Fibonacci Number
**Difficulty:** Easy | **Tags:** Recursion, Math

**Problem Statement**
The Fibonacci numbers form a sequence, called the Fibonacci sequence, such that each number is the sum of the two preceding ones, starting from 0 and 1.
$F(0) = 0, F(1) = 1$
$F(n) = F(n - 1) + F(n - 2), \text{ for } n > 1$

Given `n`, calculate `F(n)`.

**Input Format**
* A single line containing an integer `n`.

**Output Format**
* Print the $n$-th Fibonacci number.

**Constraints**
* $0 \le n \le 30$

**Examples**
**Input:** `2`
**Output:** `1`

**Input:** `3`
**Output:** `2`

**Input:** `4`
**Output:** `3`
