### Problem 78: Check if String is Palindrome or Not
**Difficulty:** Easy | **Tags:** Recursion, Strings

**Problem Statement**
Given a string `s`, return `true` if the string is palindrome, otherwise `false`. A string is called palindrome if it reads the same forward and backward. Use recursion.

**Input Format**
* A single line containing the string `s`.

**Output Format**
* Print `true` or `false`.

**Constraints**
* $1 \le s.length \le 10^3$
* `s` consists of lowercase English characters.

**Examples**
**Input:** `hannah`
**Output:** `true`

**Input:** `aabbaaa`
**Output:** `false`
