### Problem 75: Factorial of a Given Number
**Difficulty:** Easy | **Tags:** Recursion, Math

**Problem Statement**
You are given an integer `n`. Return the value of `n!` (n factorial) using recursion. Factorial of a number is the product of all positive integers less than or equal to that number. Note that $0! = 1$.

**Input Format**
* A single line containing an integer `n`.

**Output Format**
* Print the factorial of `n`.

**Constraints**
* $0 \le n \le 12$

**Examples**
**Input:** `2`
**Output:** `2`

**Input:** `0`
**Output:** `1`

**Input:** `3`
**Output:** `6`
