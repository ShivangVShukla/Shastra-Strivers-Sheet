### Problem 79: Check if a Number is Prime or Not
**Difficulty:** Easy | **Tags:** Recursion, Math

**Problem Statement**
Given an integer `num`, return `true` if it is prime otherwise `false`. A prime number is a number that is divisible only by 1 and itself. Use recursion.

**Input Format**
* A single line containing an integer `num`.

**Output Format**
* Print `true` if prime, otherwise `false`.

**Constraints**
* $1 \le num \le 10^7$

**Examples**
**Input:** `5`
**Output:** `true`

**Input:** `15`
**Output:** `false`

**Input:** `19`
**Output:** `true`
