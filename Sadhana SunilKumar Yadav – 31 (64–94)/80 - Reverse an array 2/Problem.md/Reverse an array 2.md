### Problem 80: Reverse an array 2
**Difficulty:** Easy | **Tags:** Recursion, Arrays

**Problem Statement**
Given an array `nums` of `n` integers, return reverse of the array using recursion.

**Input Format**
* The first line contains an integer `N`.
* The second line contains `N` space-separated integers.

**Output Format**
* Print the reversed array elements separated by spaces.

**Constraints**
* $1 \le N \le 10^3$
* $-10^4 \le nums[i] \le 10^4$

**Examples**
**Input:**
```
5
1 2 3 4 5
```
**Output:** `5 4 3 2 1`

**Input:**
```
5
1 3 3 3 5
```
**Output:** `5 3 3 3 1`
