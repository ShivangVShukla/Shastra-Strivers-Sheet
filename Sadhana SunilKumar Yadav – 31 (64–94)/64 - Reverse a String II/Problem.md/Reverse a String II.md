### Problem 64: Reverse a String II
**Difficulty:** Easy | **Tags:** Strings, Two Pointers

**Problem Statement**
Given a string represented by an array of characters `s`, the task is to reverse it in place with $O(1)$ extra memory.

**Input Format**
* A single line containing a string `s`.

**Output Format**
* Print the reversed string on a single line.

**Constraints**
* $1 \le s.length \le 10^5$
* `s` consists of printable characters.

**Examples**
**Input:** `hello`
**Output:** `olleh`

**Input:** `bye`
**Output:** `eyb`
