### Problem 93: Second Largest Element
**Difficulty:** Easy | **Tags:** Arrays

**Problem Statement**
Given an array of integers `nums`, return the second-largest strictly distinct element in the array. If the second-largest element does not exist, return `-1`.

**Input Format**
* The first line contains an integer `N`.
* The second line contains `N` space-separated integers.

**Output Format**
* Print the second largest integer, or `-1`.

**Constraints**
* $1 \le N \le 10^5$
* $-10^4 \le nums[i] \le 10^4$

**Examples**
**Input:**
```
5
8 8 7 6 5
```
**Output:** `7`

**Input:**
```
5
10 10 10 10 10
```
**Output:** `-1`
