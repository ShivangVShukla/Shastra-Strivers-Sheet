### Problem 81: Check if the Array is Sorted II
**Difficulty:** Easy | **Tags:** Recursion, Arrays

**Problem Statement**
Given an array `nums` of `n` integers, return `true` if the array `nums` is sorted in non-decreasing order or else `false`. Use recursion.

**Input Format**
* The first line contains an integer `N`.
* The second line contains `N` space-separated integers.

**Output Format**
* Print `true` if sorted, otherwise `false`.

**Constraints**
* $1 \le N \le 10^3$
* $-10^4 \le nums[i] \le 10^4$

**Examples**
**Input:**
```
5
1 2 3 4 5
```
**Output:** `true`

**Input:**
```
5
1 2 1 4 5
```
**Output:** `false`
