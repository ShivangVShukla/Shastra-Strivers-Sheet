### Problem 88: Quick Sorting
**Difficulty:** Medium | **Tags:** Sorting, Divide and Conquer, Quick Sort

**Problem Statement**
Given an array of integers called `nums`, sort the array in non-decreasing order using the **quick sort algorithm** and return the sorted array.

**Input Format**
* The first line contains an integer `N`.
* The second line contains `N` space-separated integers.

**Output Format**
* Print the sorted array elements separated by spaces.

**Constraints**
* $1 \le N \le 10^5$
* $-10^4 \le nums[i] \le 10^4$

**Examples**
**Input:**
```
5
7 4 1 5 3
```
**Output:** `1 3 4 5 7`
