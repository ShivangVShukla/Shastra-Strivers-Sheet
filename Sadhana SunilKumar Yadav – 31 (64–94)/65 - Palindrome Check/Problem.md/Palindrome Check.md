### Problem 65: Palindrome Check
**Difficulty:** Easy | **Tags:** Strings, Two Pointers

**Problem Statement**
You are given a string `s`. Return `true` if the string is palindrome, otherwise `false`. A string is called palindrome if it reads the same forward and backward.

**Input Format**
* A single line containing the string `s`.

**Output Format**
* Print `true` if `s` is a palindrome, otherwise `false`.

**Constraints**
* $1 \le s.length \le 10^5$
* `s` consists of lowercase English letters.

**Examples**
**Input:** `hannah`
**Output:** `true`

**Input:** `abccbd`
**Output:** `false`
