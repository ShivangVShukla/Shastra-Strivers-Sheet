### Problem 67: Longest Common Prefix
**Difficulty:** Easy | **Tags:** Strings, Prefix Matching

**Problem Statement**
Write a function to find the longest common prefix string amongst an array of strings. If there is no common prefix, return an empty string `""`.

**Input Format**
* The first line contains an integer `N`, the number of strings.
* The second line contains `N` space-separated strings.

**Output Format**
* Print the longest common prefix on a single line.

**Constraints**
* $1 \le N \le 1000$
* $0 \le str[i].length \le 1000$
* `str[i]` consists of lowercase English letters.

**Examples**
**Input:**
```
4
flowers flow fly flight
```
**Output:** `fl`

```
4
```
