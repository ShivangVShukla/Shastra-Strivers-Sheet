Editorial: Compare Two Numbers

Prerequisites:
1. Basic knowledge of Java.
2. Understanding of variables and data types.
3. Knowledge of if, else if, and else statements.
4. Understanding of comparison operators (>, <, ==).
5. Knowledge of methods and return values.

Approach:
We are given two integers A and B. Our task is to find the greater number. If both numbers are equal, we return "Equal".

Algorithm:
1. Compare A and B.
2. If A is greater than B, return A.
3. If B is greater than A, return B.
4. Otherwise, return "Equal".

Example:
Input:
8 13

Output:
13

Explanation:
Since 13 is greater than 8, the output is 13.

Complexity Analysis:
Time Complexity: O(1), because we perform a constant number of comparisons.
Space Complexity: O(1), because we use only a constant amount of extra space.
