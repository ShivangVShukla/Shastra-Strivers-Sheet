Coding Question: Compare Two Numbers

Problem Statement

Given two integers A and B, determine which number is greater. If both numbers are equal, print "Equal".

Input

A single line containing two integers A and B, separated by a space.

Output

- Print A if A is greater than B.
- Print B if B is greater than A.
- Print "Equal" if both numbers are equal.

Examples

Example 1:
Input:
8 13

Output:
13

Example 2:
Input:
20 5

Output:
20

Example 3:
Input:
7 7

Output:
Equal

Example 4:
Input:
-4 -10

Output:
-4

Constraints

-10^9 <= A, B <= 10^9
