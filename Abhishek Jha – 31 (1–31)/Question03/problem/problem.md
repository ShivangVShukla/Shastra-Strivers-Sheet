Coding Question: Check Eligibility by Age

Problem Statement

Given an integer age, determine whether a person is eligible or not.

A person is eligible if their age is greater than or equal to 18. Otherwise, the person is not eligible.

Input

A single integer age.

Output

Print "Eligible" if age is greater than or equal to 18. Otherwise, print "Not Eligible".

Examples

Example 1:
Input:
20

Output:
Eligible

Example 2:
Input:
16

Output:
Not Eligible

Example 3:
Input:
18

Output:
Eligible

Constraints

0 <= age <= 150
