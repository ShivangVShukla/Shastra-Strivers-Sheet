Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Print the upper half using rows from n down to 1.
2. For each row, print the same number of stars on the left and right.
3. Print 2 * (n - row) spaces between the two star groups.
4. Print the lower half using rows from 1 to n.

Time Complexity: O(n²)

Space Complexity: O(1)
