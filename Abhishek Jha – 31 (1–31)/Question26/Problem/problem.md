Coding Question: Pattern 21

Given an integer n, print the following pattern.

For n = 5, the pattern should look like this:

*****
*   *
*   *
*   *
*****

Example 1:
Input: n = 4

Output:
****
*  *
*  *
****

Example 2:
Input: n = 2

Output:
**
**

Constraints:
1 <= n <= 100

Task: Complete the function to print the required pattern.
