Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Conditional statements
5. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. For the first and last rows, print stars in every column.
3. For the remaining rows, print stars only in the first and last columns.
4. Print spaces inside the rectangle and move to the next line.

Time Complexity: O(n²)

Space Complexity: O(1)
