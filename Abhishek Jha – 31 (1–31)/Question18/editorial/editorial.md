Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. Maintain a counter starting at 1.
3. For each row i, print i consecutive values from the counter.
4. Increment the counter after every value and move to the next line after each row.

Time Complexity: O(n²)

Space Complexity: O(1)
