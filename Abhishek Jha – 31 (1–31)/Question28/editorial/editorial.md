Editorial

Prerequisites:
1. While loops
2. Integer division
3. Basic Java Syntax
4. Printing Output

Approach:
1. If n is 0, it has exactly one digit.
2. Otherwise, repeatedly divide n by 10.
3. Count how many divisions are performed before n becomes 0.
4. Print the digit count.

Time Complexity: O(log n)

Space Complexity: O(1)
