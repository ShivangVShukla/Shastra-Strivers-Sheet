Coding Question: Sum of Digits

Problem Statement:
Write a Java program that takes a non-negative integer N as input and calculates the sum of its digits.

Input Format:
A single non-negative integer N.

Output Format:
Print the sum of the digits of N.

Constraints:
0 <= N <= 1000000000

Sample Input 1:
472

Sample Output 1:
13

Sample Input 2:
105

Sample Output 2:
6

Sample Input 3:
9

Sample Output 3:
9

Sample Input 4:
0

Sample Output 4:
0
