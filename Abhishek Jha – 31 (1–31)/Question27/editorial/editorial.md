Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Math.min
5. Printing Output

Approach:
1. Create a square with side length 2 * n - 1.
2. For each cell, calculate its minimum distance from the four borders.
3. The value in the cell is n minus that minimum distance.
4. Print spaces between values and move to the next line after each row.

Time Complexity: O(n²)

Space Complexity: O(1)
