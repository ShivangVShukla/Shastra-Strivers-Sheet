Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Character arithmetic
5. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. For each row i, print the first i uppercase letters.
3. Convert each column index into a character by adding it to 'A'.
4. Move to the next line after printing each row.

Time Complexity: O(n²)

Space Complexity: O(1)
