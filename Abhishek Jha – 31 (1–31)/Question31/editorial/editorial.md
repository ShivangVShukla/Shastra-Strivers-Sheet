Editorial

Prerequisites:
1. While loops
2. Modulo operator
3. Integer division
4. Basic Java Syntax
5. Conditional statements

Approach:
1. Store the original number.
2. Reverse the digits using modulo 10 and integer division by 10.
3. Compare the reversed number with the original number.
4. Print true when they are equal; otherwise, print false.

Time Complexity: O(log n)

Space Complexity: O(1)
