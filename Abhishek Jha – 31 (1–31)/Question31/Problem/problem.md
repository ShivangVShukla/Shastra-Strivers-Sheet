Coding Question: Check Palindrome Number

You are given an integer n. Check whether the number is a palindrome.
Return true if it is a palindrome; otherwise, return false.

A palindrome number reads the same from left to right and right to left.

Example 1:
Input: n = 121

Output:
true

Explanation: 121 reads the same in both directions.

Example 2:
Input: n = 123

Output:
false

Explanation: 123 reads as 321 from right to left.

Constraints:
0 <= n <= 5000

Task: Complete the function to check whether n is a palindrome.
