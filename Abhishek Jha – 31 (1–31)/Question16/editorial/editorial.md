Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. For each row i, start with 1 when i is odd and 0 when i is even.
3. Print i values, alternating between 0 and 1.
4. Print a space between values and move to the next line after each row.

Time Complexity: O(n²)

Space Complexity: O(1)
