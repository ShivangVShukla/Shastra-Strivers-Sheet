Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. Print the increasing sequence from 1 to the current row.
3. Print 2 * (n - row) spaces between the two halves.
4. Print the decreasing sequence from the current row down to 1.
5. Move to the next line after printing each row.

Time Complexity: O(n²)

Space Complexity: O(1)
