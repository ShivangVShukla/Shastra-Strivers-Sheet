Coding Question: Pattern 12

Given an integer n, print the following pattern.

For n = 5, the pattern should look like this:

1        1
12      21
123    321
1234  4321
1234554321

Example 1:
Input: n = 4

Output:
1      1
12    21
123  321
12344321

Example 2:
Input: n = 2

Output:
1 1
1221

Constraints:
1 <= n <= 100

Task: Complete the function to print the required pattern.
