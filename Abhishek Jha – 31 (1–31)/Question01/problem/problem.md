Coding Question: Even or Odd
Problem Statement

Given an integer N, determine whether it is even or odd.

An integer is even if it is divisible by 2 with a remainder of 0. Otherwise, it is odd.

Input

A single integer N.

Output

Print "Even" if N is even; otherwise, print "Odd".

Examples

Example 1: Input: 8

Output: Even

Example 2: Input: 7

Output: Odd

Constraints

-10^9 <= N <= 10^9
