Editorial

Prerequisites:
1. While loops
2. Modulo operator
3. Integer division
4. Basic Java Syntax
5. Printing Output

Approach:
1. Extract the last digit using n % 10.
2. Append it to the reversed number by multiplying the current result by 10.
3. Remove the last digit from n using integer division by 10.
4. Repeat until all digits have been processed.
5. Print the reversed number.

Time Complexity: O(log n)

Space Complexity: O(1)
