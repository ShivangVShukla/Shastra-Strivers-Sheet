Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Character arithmetic
5. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. Convert the row index into a letter by adding it to 'A'.
3. Print the same letter row times.
4. Move to the next line after printing each row.

Time Complexity: O(n²)

Space Complexity: O(1)
