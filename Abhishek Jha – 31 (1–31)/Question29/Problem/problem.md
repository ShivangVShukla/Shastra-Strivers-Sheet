Coding Question: Count Odd Digits

You are given an integer n. Return the number of odd digits present in the number.

The number has no leading zeroes, except when the number is 0 itself.

Example 1:
Input: n = 5

Output:
1

Explanation: 5 is an odd digit.

Example 2:
Input: n = 25

Output:
1

Explanation: The only odd digit in 25 is 5.

Constraints:
0 <= n <= 5000

Task: Complete the function to return the number of odd digits in n.
