Editorial

Prerequisites:
1. While loops
2. Modulo operator
3. Integer division
4. Basic Java Syntax
5. Printing Output

Approach:
1. Extract each digit using n % 10.
2. Check whether the digit is odd using digit % 2.
3. Increase the count when the digit is odd.
4. Divide n by 10 to remove the last digit.
5. Continue until all digits have been processed.

Time Complexity: O(log n)

Space Complexity: O(1)
