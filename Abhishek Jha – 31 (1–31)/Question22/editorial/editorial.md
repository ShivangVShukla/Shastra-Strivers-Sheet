Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Character arithmetic
5. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. Print n - row leading spaces to center the row.
3. Print letters from A through the row's peak letter.
4. Print letters from one before the peak back down to A.
5. Move to the next line after printing each row.

Time Complexity: O(n²)

Space Complexity: O(1)
