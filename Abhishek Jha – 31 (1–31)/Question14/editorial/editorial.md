Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Print the upper half using rows from 1 to n.
2. For each row, print n - i leading spaces and 2 * i - 1 stars.
3. Print the lower half using rows from n down to 1.
4. For each lower row, print n - i leading spaces and 2 * i - 1 stars.

Time Complexity: O(n²)

Space Complexity: O(1)
