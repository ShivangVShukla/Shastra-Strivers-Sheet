Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Character arithmetic
5. Printing Output

Approach:
1. Start an outer loop from 0 to n - 1.
2. The first letter in row i is 'A' + n - i - 1.
3. Print letters from the row's first letter through the letter at 'A' + n - 1.
4. Move to the next line after printing each row.

Time Complexity: O(n²)

Space Complexity: O(1)
