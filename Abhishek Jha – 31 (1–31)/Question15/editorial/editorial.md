Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Print the upper half using row widths from 1 to n.
2. Print the lower half using row widths from n - 1 down to 1.
3. For each row, print the required number of stars.
4. After printing each row, move to the next line using System.out.println().

Time Complexity: O(n²)

Space Complexity: O(1)
