Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Start an outer loop from 1 to n.
2. For each row i, run an inner loop from 1 to i.
3. Print the number i in each iteration of the inner loop.
4. After printing each row, move to the next line using System.out.println().

Time Complexity: O(n²)

Space Complexity: O(1)
