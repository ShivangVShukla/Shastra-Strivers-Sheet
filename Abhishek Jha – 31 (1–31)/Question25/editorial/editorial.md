Editorial

Prerequisites:
1. For Loops
2. Nested Loops
3. Basic Java Syntax
4. Printing Output

Approach:
1. Print the upper half using star counts from 1 to n.
2. For each row, print the same number of stars on both sides.
3. Print 2 * (n - row) spaces between the two star groups.
4. Print the lower half using star counts from n - 1 down to 1.

Time Complexity: O(n²)

Space Complexity: O(1)
