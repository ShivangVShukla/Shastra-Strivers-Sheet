Right-Angled Triangle Star Pattern
Problem Statement

Given an integer n, print a right-angled triangle pattern using stars (*) with n rows.

The first row should contain one star, the second row should contain two stars, and each subsequent row should contain one more star than the previous row.

Example 1

Input
4
Output
*
**
***
****

Example 2

Input
2
Output
*
**

Constraints
1 <= n <= 100
Input Format

A single integer n, representing the number of rows.

Output Format

Print the right-angled triangle pattern of stars, with each row printed on a new line.
